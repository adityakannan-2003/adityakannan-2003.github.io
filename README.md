# adityakannan-2003.github.io

My portfolio: one static page, `index.html`, plus `images/demo.gif`. No build step. GitHub Pages serves it at https://adityakannan-2003.github.io from `main`.

Every figure on the page comes from a README, `docs/METRICS.md` or a results file in the project repos. Check them again when those repos change.

To preview locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
